# Portfolio · Hamid Zidelmal

Portfolio de Hamid Zidelmal, Data Engineer Azure & Databricks à Paris.

En ligne : https://hxxmid.github.io/portfolio/

## Contenu

- Pipeline animé (sources → Azure Data Factory → Bronze → Silver → Gold → Power BI), interactif au survol
- Résultats chiffrés, parcours, projets, stack, formation et contact

## Technique

Site statique sans dépendance : `index.html`, `style.css`, `script.js`.
Polices : Bricolage Grotesque et Instrument Sans (Google Fonts).
Les animations respectent le réglage système « réduire les animations ».

Pour le lancer en local, ouvrez `index.html` dans un navigateur.
